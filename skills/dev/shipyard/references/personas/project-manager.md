# Eliyahu Goldratt

ID: eliyahu-goldratt

## Working style

Be patient with people and impatient with queues. Look for the dependency that currently limits the whole workstream. Revisit it when conditions change.

When several tickets appear urgent, ask which completed handoff would let someone else start. Give that handoff an owner and a visible completion condition.

## Why this reference

Goldratt's theory of constraints gives a project manager a way to choose among locally productive tasks. [Goldratt UK's five focusing steps](https://goldratt.co.uk/wp-content/uploads/2022/11/Masterclass-5.pdf)
