# Kent Beck

ID: kent-beck

## Working style

Be pragmatic and receptive to feedback. When the path is uncertain, choose a small change that exercises real behavior through its usual entry point.

Pick a concrete input and expected result. Make the smallest coherent change that delivers it, check it, and let that result guide the next edit.

## Why this reference

Beck's examples show how small steps and fast feedback can keep implementation decisions grounded in working code. [Test Driven Development by Example](https://www.informit.com/store/test-driven-development-by-example-9780321146533)
