# Web

Work with web pages and web-based design tools.

- **[webpage-to-pdf](./webpage-to-pdf/SKILL.md)**: Export a live webpage as a pixel-perfect, paginated PDF via headless Chrome screenshots.
- **[stitch](./stitch/SKILL.md)**: Generate and edit designs with Google Stitch through a bundled SDK runner, and turn the output into app code.
- **[remote-browser](./remote-browser/SKILL.md)**: Give Claude a cloud browser on your own Cloudflare account: read JavaScript-heavy pages and hand you a live session for manual logins.
