# In Progress

Beta. These skills are public on purpose: try them and report what breaks. They are excluded from the plugin and the top-level README until they graduate to a stable bucket, and they can change or disappear without warning.

The plugin does not include these. Install one directly:

```bash
npx skills@latest add itamaker/skills --skill=<name>
```

- **[remote-browser](./remote-browser/SKILL.md)**: Give Claude a cloud browser on your own Cloudflare account: read JavaScript-heavy pages and hand you a live session for manual logins.
